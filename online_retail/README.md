Customer Return Prediction (Online Retail)
Описание

Проект посвящён задаче предсказания возврата клиентов интернет-магазина на основе истории их транзакций. Задача сформулирована как бинарная классификация на уровне клиента.

Данные

Используется датасет Online Retail с транзакциями:

InvoiceNo, InvoiceDate

CustomerID

Quantity, UnitPrice

Country

Каждая строка соответствует позиции товара в заказе.

Target

Target = 1, если клиент совершил хотя бы одну покупку после cutoff даты.
Target = 0, если клиент не вернулся.

Cutoff: 2011-11-01

Горизонт прогнозирования: 1 месяц

Feature Engineering

Фичи агрегированы на уровне клиента и рассчитаны по данным до cutoff:

number_of_orders — количество заказов

revenue — суммарная выручка

mean_check — средний чек

days_from_purchase — дни с последней покупки

Для денежных признаков применено лог-преобразование.

Модели и результаты

Обучены и сравнены несколько моделей:

Модель	ROC-AUC
Logistic Regression	~0.64
LogReg + preprocessing	~0.67
CatBoostClassifier	~0.72

CatBoost показал наилучшее качество за счёт учёта нелинейных зависимостей.

Выводы

Ключевым фактором возврата клиента является давность последней покупки, а также частота заказов. Регулярность покупок оказалась важнее размера одного чека.

Ограничения

Используется только транзакционная история

Горизонт прогнозирования — 1 месяц
